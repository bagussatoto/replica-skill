# Test Plan: LinkHub (Bio Link Platform)

Generated by: `replica-test` simulation

## Flows

### F01: Public Visitor Clicks a Bio Link
- **F01-H1 (Happy path)**: Visitor opens `/demo`, sees profile avatar and active links, clicks first link, and is redirected while click counter increments by 1.
- **F01-E1 (Double click)**: Visitor double-clicks link rapidly; redirect succeeds without server 500 error.
- **F01-N1 (Unknown username)**: Visitor opens `/nonexistent-user-999` and sees a clean 404 page with a CTA to claim the username.

### F02: Creator Adds and Reorders Links
- **F02-H1 (Happy path)**: Creator signs in to `/admin`, adds a new link with title and URL, drags it to position 1, and sees the live preview update immediately.
- **F02-E1 (Invalid URL)**: Creator enters `javascript:alert(1)` or plain text without scheme; form shows validation error and refuses to save.
- **F02-N1 (Unauthorized access)**: Unauthenticated user requests `POST /api/links` and receives `401 Unauthorized`.
