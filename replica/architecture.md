## 2. Database Schema (SQL)

```sql
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  username VARCHAR(40) UNIQUE NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  display_name VARCHAR(80),
  bio TEXT,
  avatar_url TEXT,
  theme_id VARCHAR(32) DEFAULT 'clean-light',
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE links (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  title VARCHAR(120) NOT NULL,
  url TEXT NOT NULL,
  position INTEGER NOT NULL DEFAULT 0,
  is_active BOOLEAN NOT NULL DEFAULT true,
  clicks INTEGER NOT NULL DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE INDEX idx_links_user_pos ON links (user_id, position);
```

## 3. Build Order
1. Public profile route (`/[username]`) rendering active links in position order.
2. Click redirect endpoint (`/api/r/[linkId]`) incrementing click count atomically.
3. Admin link editor (`/admin`) with create, toggle, reorder, and delete.
4. Theme selector and QR code generator.
